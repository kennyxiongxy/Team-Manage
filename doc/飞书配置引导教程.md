# 飞书配置引导教程

本教程帮你一步步完成「AI 团队管理助手」与飞书的集成配置。

---

## 一、先理解系统怎么连飞书

本系统**不是直接调用飞书 OpenAPI**，而是通过「飞书命令行工具 `lark-cli`」作为桥梁来读写你的飞书数据。

**好处**：你不需要申请飞书开发者应用、不需要处理复杂的 OAuth 授权流程，只要你的飞书账号能正常登录，系统就能操作你账号下的表格和通讯录。

**依赖链**：

```
本系统前端 → 本系统后端 → lark-cli → 飞书服务器
```

所以整个配置的核心就两件事：
1. **你的电脑上，lark-cli 已经登录了飞书**（这是前提）
2. **系统里保存了你的飞书应用标识**（用于系统内部记录）

---

## 二、配置前检查清单

打开终端，依次执行以下命令检查：

```bash
# 1. 检查 lark-cli 是否已安装
lark-cli --version
# 预期输出：lark-cli version x.x.x

# 2. 检查 lark-cli 是否已登录
lark-cli auth whoami --format json
# 预期输出：显示你的飞书用户名和邮箱
```

**如果第 1 步报错**（command not found），先安装 lark-cli：
```bash
npm install -g @larksuiteoapi/lark-cli
```

**如果第 2 步未显示用户信息**，先登录：
```bash
lark-cli auth login
# 会弹出浏览器让你扫码登录飞书
```

> 只有 lark-cli 登录成功，系统才能读写你的飞书数据。这是最关键的一步。

---

## 三、进入系统配置飞书

### 步骤 1：打开飞书集成页面

用 **manager（管理员）** 账号登录系统，点击左侧导航「飞书集成」。

页面有 4 个 Tab：
- **连接配置** — 填写 App ID / App Secret，保存连接状态
- **通讯录** — 查看飞书通讯录成员
- **表格管理** — 查看已连接的飞书表格
- **同步日志** — 查看数据同步记录

### 步骤 2：填写并保存配置

切换到「连接配置」Tab，你会看到三个输入框：

| 字段 | 说明 | 怎么填 |
|------|------|--------|
| **App ID** | 飞书应用的标识 | 暂时可随意填写一个标识字符串，如 `my-app-001` |
| **App Secret** | 飞书应用的密钥 | 暂时可随意填写，如 `placeholder-secret` |
| **Webhook URL** | 飞书机器人推送地址 | 可选，有 webhook 时填写 |

> **为什么是"暂时可随意填写"？**
> 当前系统所有飞书操作都通过 `lark-cli` 执行，使用的是你个人账号的权限，**不依赖** App ID 和 App Secret 调用飞书 API。这两个字段目前主要用于系统内部标识记录，以及预留将来直接调用飞书开放平台 API 的扩展能力。

点击「保存配置」，提示保存成功后，配置信息会存入系统本地数据库。

### 步骤 3：测试连接并启用

保存后，点击「连接测试」按钮。如果 lark-cli 已正确登录，会提示**连接测试成功**。

然后打开「启用飞书集成」开关，系统状态变为「已连接」。

此时页面下方的「已连接表格」区域会自动加载你飞书账号下的所有多维表格。

---

## 四、连接飞书表格（数据映射）

系统支持两种方式使用飞书表格：

### 方式 A：一键创建标准表格（推荐新手）

在「飞书集成」页面，点击「一键创建标准表格」按钮。系统会调用飞书 API，在你的飞书空间中自动创建一个名为「团队任务管理」的多维表格，并预设好 5 张子表：

| 子表名称 | 用途 |
|---------|------|
| 数据表 | 通用数据存储 |
| 任务跟踪 | 对应系统任务模块 |
| 项目管理 | 对应系统项目模块 |
| 日报汇总 | 对应系统日报模块 |
| 求助处理 | 对应系统求助模块 |

创建成功后，你会在飞书文档中看到这个表格。然后进入「数据映射配置」页面，选择刚刚创建的表格，完成字段映射即可。

### 方式 B：手动创建并连接（推荐已有表格的用户）

如果你已经在飞书中有现成的多维表格，可以直接连接：

1. **在飞书中准备表格**
   - 确保表格是「多维表格」（不是普通表格）
   - 至少包含「任务名称」「负责人」「任务状态」等字段
   - 具体字段规范参考 `doc/飞书表格搭建规范.md`

2. **在系统中搜索并选择**
   - 进入「飞书集成 → 表格管理」Tab
   - 系统会自动列出你飞书账号下的所有多维表格
   - 或者使用搜索框输入表格名称关键词查找

3. **进入数据映射配置**
   - 点击「数据映射配置」或在表格列表中选择一张表格
   - 系统会读取该表格的字段列表
   - 将飞书字段与系统字段一一对应（支持 AI 智能匹配）
   - 点击「保存映射」

---

## 五、验证配置是否成功

配置完成后，验证以下功能是否正常：

1. **通讯录同步**：在「飞书集成 → 通讯录」Tab，应能看到你的飞书团队成员列表
2. **表格读取**：在「飞书集成 → 表格管理」Tab，应能搜索并看到你创建的表格
3. **字段读取**：进入「数据映射配置」页面，选择表格后，下拉框应能加载字段列表
4. **数据同步**：在「飞书同步」页面，点击同步按钮，系统会将飞书表格的数据同步到本地（或将本地数据同步到飞书）

## 六、常见问题排查

### Q1: 保存配置时提示"用户不存在"

**原因**：后端热重载时触发了 seed，清空了用户表。  
**解决**：重新登录系统即可，token 会自动更新。

### Q2: 表格下拉框为空，无法选择

**原因**：前端代码中 API 响应解析层级错误（已修复）。  
**解决**：刷新页面后重新进入「数据映射配置」。

### Q3: 飞书通讯录显示为空

**原因**：lark-cli 未登录，或登录的账号没有通讯录权限。  
**解决**：
```bash
lark-cli auth whoami --format json
# 确认显示的是有权限的账号
```

### Q4: 一键创建表格失败

**原因**：lark-cli 权限不足，或网络问题。  
**解决**：检查 lark-cli 登录状态，或手动在飞书中创建表格后再连接。

### Q5: 同步数据时部分字段映射不上

**原因**：飞书表格字段名称与系统标准字段名称差异太大。  
**解决**：在「数据映射配置」页面手动选择对应字段，或修改飞书表格字段名使其更规范。

## 八、总结

| 步骤 | 动作 | 必须？ |
|------|------|--------|
| 安装 lark-cli | `npm install -g @larksuiteoapi/lark-cli` | 是 |
| 登录飞书 | `lark-cli auth login` | 是 |
| 保存系统配置 | 前端填写 App ID / Secret | 是（至少占位） |
| 启用连接 | 前端点击启用 | 是 |
| 创建/连接表格 | 一键创建 或 手动选择 | 是 |
| 字段映射 | 数据映射配置页面 | 视功能需求 |
| 数据同步 | 飞书同步页面 | 视功能需求 |

只要前 4 步完成，系统就能读取你的飞书通讯录和表格。后 3 步根据你实际使用的功能来决定是否需要配置。
