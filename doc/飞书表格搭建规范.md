# 飞书表格搭建规范

> 本文档说明本系统依赖的核心数据表结构，以及如何在飞书多维表格中搭建对应表格，便于未来一键导入或同步数据。

---

## 一、系统概述

本系统是一个 AI 团队管理助手，核心功能包括任务管理、项目追踪、日报汇总、人员管理。系统的底层依赖以下 5 张核心数据表：

| 序号 | 数据表 | 用途 | 是否必须搭建飞书表格 |
|------|--------|------|-------------------|
| 1 | 任务表 | 存储所有任务数据，最核心的业务表 | 强烈建议 |
| 2 | 项目表 | 存储项目基本信息 | 建议 |
| 3 | 员工表 | 存储团队成员信息 | 可选（可从飞书通讯录同步） |
| 4 | 日报表 | 存储每日工作汇报 | 可选 |
| 5 | 求助表 | 存储成员求助记录 | 可选 |

> 建议至少搭建「任务表」和「项目表」，即可覆盖系统 80% 的核心功能。

---

## 二、飞书表格搭建规范

### 2.1 任务表（核心）

**飞书表格名称建议**：`团队任务管理` / `任务跟踪表` / `TODO清单`

| 字段名称建议 | 飞书字段类型 | 是否必填 | 系统映射字段 | 说明 |
|-------------|-------------|---------|-------------|------|
| 任务名称 | 文本 | 是 | title | 任务标题，系统通过关键词"名称/标题/任务"识别 |
| 负责人 | 人员 | 否 | assignee | 任务执行人，系统通过关键词"负责人/执行人/指派"识别 |
| 任务状态 | 单选 | 否 | status | 建议选项：未开始、进行中、待评审、已完成、已逾期 |
| 优先级 | 单选 | 否 | priority | 建议选项：紧急、高、中、低 |
| 截止日期 | 日期 | 否 | dueDate | 任务截止日期，系统通过关键词"截止/结束/期限"识别 |
| 完成进度 | 数字 | 否 | progress | 0-100 的整数，表示完成百分比 |
| 任务描述 | 文本 | 否 | description | 详细描述，系统通过关键词"描述/详情"识别 |
| 所属项目 | 文本/单选 | 否 | project | 关联的项目名称，系统通过关键词"项目"识别 |
| 标签 | 多选 | 否 | tags | 任务分类标签 |

**飞书字段类型设置参考**：
- 文本：直接输入
- 人员：飞书「人员」字段，可直接@成员
- 单选：设置固定选项列表
- 多选：设置固定选项列表
- 日期：飞书「日期」字段
- 数字：飞书「数字」字段，范围 0-100

**字段映射关键词对照**：
系统通过 AI 智能分析飞书表格的字段名称来自动映射，支持以下关键词：

| 系统字段 | 识别的关键词（任一即可） |
|---------|------------------------|
| title（任务标题） | 任务名称、标题、名称、任务 |
| assignee（负责人） | 负责人、执行人、指派 |
| status（任务状态） | 状态、进展 |
| priority（优先级） | 优先级、重要程度 |
| dueDate（截止日期） | 截止日期、结束日期、期限 |
| progress（完成进度） | 进度、完成度、百分比 |
| description（任务描述） | 描述、详情 |
| project（所属项目） | 项目 |
| tags（标签） | 标签 |

## 三、飞书字段类型与系统类型对照

系统支持映射的飞书多维表格字段类型如下：

| 飞书字段类型（UI 编号） | 飞书显示名称 | 系统映射类型 | 适用场景 |
|----------------------|-------------|-------------|---------|
| 1 | 文本 | text | 标题、描述、项目名称等 |
| 2 | 数字 | number | 进度百分比、评分等 |
| 3 | 单选 | singleSelect | 状态、优先级、阶段等 |
| 4 | 多选 | multiSelect | 标签、分类等 |
| 5 | 日期 | date | 截止日期、开始日期等 |
| 7 | 复选框 | checkbox | 是否完成标记 |
| 11 | 人员 | user | 负责人、执行人等 |
| 13 | 超链接 | url | 相关链接 |
| 15 | 进度 | progress | 完成进度条 |
| 100 | 电话 | phone | 联系方式 |

> 在飞书中创建字段时，优先使用「人员」字段存储负责人，使用「日期」字段存储时间，这样系统识别和映射的准确率最高。

## 四、搭建步骤建议

### 步骤 1：创建飞书多维表格
在飞书云文档中新建一个「多维表格」，命名为「团队任务管理」。

### 步骤 2：添加字段
按照上表中的规范添加字段，建议至少包含：
- 任务名称（文本）
- 负责人（人员）
- 任务状态（单选）
- 优先级（单选）
- 截止日期（日期）

### 步骤 3：填充示例数据
添加 3-5 条示例任务记录，确保字段内容格式正确。

### 步骤 4：在系统中连接
进入系统的「飞书集成 → 表格管理」页面，搜索并选择刚刚创建的表格，完成字段映射配置。

## 五、注意事项

1. **字段名称尽量规范**：使用上述建议的字段名称（如"任务名称"、"负责人"），系统 AI 映射的准确率会更高。如果字段名称与规范差异较大，可在映射页面手动调整。

2. **单选字段选项建议统一**：
   - 任务状态建议统一为：未开始、进行中、待评审、已完成、已逾期
   - 优先级建议统一为：紧急、高、中、低
   
   系统会自动将飞书的选项值转换为系统标准值。

3. **人员字段的优势**：飞书的「人员」字段可以直接@飞书成员，系统导入时会自动匹配到系统用户。如果使用纯文本字段存储姓名，则需要手动映射。

4. **日期格式**：飞书的「日期」字段系统可直接识别，无需额外格式设置。

5. **数字字段范围**：完成进度建议使用 0-100 的整数，表示百分比。

6. **表格命名**：表格名称不需要严格匹配规范中的建议名称，系统通过搜索关键词查找表格。

## 七、后续扩展：一键创建

未来计划实现的功能：在系统中点击「一键创建飞书表格」，自动调用飞书 API 在用户的飞书空间中创建符合上述规范的标准表格，无需手动搭建。

实现该功能需要：
1. 调用飞书「创建多维表格」API
2. 按规范批量创建字段
3. 设置单选字段的选项列表
4. 预填充示例数据
